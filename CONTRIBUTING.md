# Contributing to Clinician-Unchained

Thank you for your interest in contributing to Clinician-Unchained! We welcome contributions from everyone.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your feature or fix
4. Make your changes
5. Test thoroughly
6. Submit a pull request

## Development Setup

```bash
# Install dependencies
pnpm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Code Style

- Use TypeScript for new code
- Follow existing code formatting
- Use meaningful variable and function names
- Add comments for complex logic
- Write unit tests for new features

## Commit Messages

Use clear, descriptive commit messages:
- `feat: Add new feature description`
- `fix: Fix bug description`
- `docs: Update documentation`
- `refactor: Code improvements`
- `test: Add or update tests`

## Pull Request Process

1. Update README if needed
2. Add tests for new functionality
3. Ensure all tests pass
4. Request review from maintainers
5. Address feedback and merge when approved

## Reporting Issues

- Use the issue tracker
- Provide clear description
- Include steps to reproduce
- Add relevant screenshots/logs

Thank you for contributing!
